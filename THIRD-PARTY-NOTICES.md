## Embedded assets and resources not shipped as dependencies

- Auxora's embedded HTML, CSS, JavaScript, application icon, and `assets/icons/auxora-mark.svg` are repository-owned project assets. No third-party JavaScript framework, font file, stock image, or media file is bundled in the Windows publish.
- `index.html`, `hosted-dashboard.html`, and the legacy standalone clock page can request Inter and Roboto from Google Fonts when used as hosted web pages. Those font files are not bundled in the Windows installer. Inter and Roboto are available under the SIL Open Font License 1.1.
- Weather icons are requested from OpenWeatherMap at runtime and album artwork comes from the user's Windows media session. They are not copied into or redistributed with Auxora.
- This beta does not bundle the Microsoft Edge WebView2 Evergreen Runtime. `Microsoft.Web.WebView2` above is the loader/control package shipped with the app; setup requires the separately installed Evergreen Runtime.

## Build and test dependencies not shipped in the Windows app

The following dependency groups are intentionally excluded from the shipped runtime inventory:

- `Microsoft.Windows.CsWin32` 0.3.298, `Microsoft.Windows.SDK.Win32Docs` 0.1.42-alpha, `Microsoft.Windows.SDK.Win32Metadata` 70.0.11-preview, and `Microsoft.Windows.WDK.Win32Metadata` 0.13.25-experimental are source-generation inputs. `Microsoft.Windows.CsWin32` is marked `PrivateAssets="all"` and none of these packages contributes a runtime binary to the Windows publish.
- `Microsoft.Windows.SDK.BuildTools` 10.0.26100.4654 and `Microsoft.Windows.SDK.BuildTools.MSIX` 1.7.20250829.1 are build-only tooling.
- The Android, Linux, macOS, and Mac Catalyst `runtime.*.System.IO.Ports` packages appear in the cross-platform restore graph but contribute no `win-x64` runtime asset.
- `Microsoft.NET.Test.Sdk`, NUnit, and NUnit3TestAdapter belong only to `app/tests`.
- Electron and electron-builder are development-only dependencies of the separate macOS prototype under `desktop/electron`; they are not included in the WinUI Windows beta.
- The root Node package has no production dependencies. Node.js is used only for development checks and the legacy local bridge, not packaged in the native Windows installer.
